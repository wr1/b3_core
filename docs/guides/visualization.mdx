Figures and reports are optional — they are not required for FEA handoff. The
`b3_core.viz` layer shares one model cache (`CoreModel`), one theme (`CoreTheme`),
and a fluent scene builder (`CoreScene`).

## One-call view

```python
from b3_core.viz import GroovedCoreView

view = GroovedCoreView.from_json("examples/mfem_patterns/two_sided.json")
view.gallery("board.png")                 # composite publication board
view.modulus_surface_png("modulus.png")   # directional E(n)
view.show()                               # native interactive window
view.serve("core.html")                   # HTML viewer ([interactive] extra)
```

```bash
uv run b3_core viz view examples/mfem_patterns/two_sided.json --what gallery -o board.png
uv run b3_core viz view case.json --what all -o out_dir/
```

`--what` accepts: `geometry`, `slices`, `deformation`, `modulus`, `polar`,
`heatmap`, `gallery`, `all`.

## Kerf on a curve vs flattened RVE

- **On the mould:** rectangular foam lands; kerfs = hinged gaps (motivates κ).
- **Flattened FEA:** `slope = −sign(d)·κ·p/2` → `hw(z)` morph (what is solved).

```bash
uv run python examples/curved_panel/render.py
# open:   examples/curved_panel/img/groove_curved_vs_flat.png
# closed: examples/curved_panel/img/groove_curved_vs_flat_closed.png
```

## Architecture of the viz stack

```
src/b3_core/viz/
├── theme.py      CoreTheme — colours, cmaps, opacities
├── model.py      CoreModel — cached mesh / geom / MFEM fields
├── geometry.py   phase split, slab pick, plane sampling
├── tensor.py     directional E/G/ν from C_eff; modulus surface
├── tensorplot.py signed 6×6 heatmap, polar E(θ)
├── slices.py     plan / top / side cuts + mesh
├── scene.py      CoreScene fluent pyvista builder
├── view.py       GroovedCoreView facade + CLI
├── halo.py       halo figure bundle
└── animate.py    social-media explainer (MP4/GIF, [anim] extra)
```

Datasheet and deformed CLIs build on this layer; they do not reimplement meshing.
