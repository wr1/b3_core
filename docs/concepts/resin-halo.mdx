Grid-scoring does more than cut a neat kerf: the saw **opens foam cells** along
the walls and root. During infusion those cells take resin, so the real section
is graded — not a binary foam | resin paint job.

## What the halo looks like

Through-thickness view of one kerf: **neat resin** in the slot, a **resin-rich
halo** of opened cells, then **intact foam**. Halo width tracks foam cell size
(reach ≈ `cell_size`).

<img
  src="/figures/halo_schematic_zones.png"
  alt="Schematic: central neat resin kerf, orange halo bands of opened cells, grey intact foam on both sides, reach marked as cell_size."
  className="my-6 w-full max-w-3xl mx-auto rounded-lg border border-fd-border"
/>

Laustsen et al. (2014) CT scans show this band is **wider than the nominal
slit** and depends on density — smaller cells (e.g. H130) → thinner halo than
larger cells (e.g. H60). `b3_core` models that band explicitly instead of folding
it into a single calibrated failure strain.

## How stiffness is graded

Distance `d` [mm] is measured from each foam Gauss point to the nearest **cut
surface** (groove walls + root). Unsawn outer faces use a thinner closed-cell
halo (default `0.25 ×` saw-cut reach).

```
P(resin) = max( S_saw(d_to_groove), S_face(d_to_outer_face) )
C_local  = P · C_resin + (1 − P) · C_foam
```

`S(d)` is the cell-size survival: `S(0)=1` at the cut, `S→0` at reach.

| Surface | Where | Cell state | Default reach |
|---------|-------|------------|---------------|
| `saw_cut` | Groove walls + root | Opened by saw/knife | from `core.cell_size` |
| `face` | Unsawn `z=0` / `z=thickness` | Closed cells | `0.25 ×` saw-cut |

Bigger cells ⇒ longer reach ⇒ wider resin-rich band ⇒ **higher homogenized
moduli** (tests: `Ezz` rises with `cell_size`).

## Textile-as-code (how to turn it on)

Prefer factories over hand-written JSON. Halo is one modifier (or built into
`grid_scored`):

```python
from b3_core import grid_scored, homogenize, uniaxial

# DIAB-style grid score + 0.6 mm halo (numpy backend auto)
case = grid_scored(cell_size=0.6)
result = homogenize(case)

# Any textile: add halo later
case = uniaxial().with_halo(0.6, face_enabled=True)
# Sharp twin (no halo):
sharp = grid_scored(with_halo=False, cell_size=None)
```

Optional JSON snapshot for CLI:

```python
grid_scored(cell_size=0.6).to_json("gs30_scored.json")
# uv run b3_core run gs30_scored.json
```

```bash
uv run python examples/textile_gs30.py
uv run b3_core viz halo examples/diab_gs30_scored.json \
  -o examples/img --sharp examples/diab_gs30.json
```

### `core.cell_size` [mm]

| Form | Meaning | Survival `S(d)` |
|------|---------|-----------------|
| omitted / `null` | No halo — sharp kerf only | — |
| scalar `0.6` | Uniform cells in `[0, cs]` | `S(d) = 1 − d/cs` |
| `{mean, std, dist}` | Distributed size | `lognormal` (default) or `normal`, `S(0)=1` |

### `scoring` block (advanced)

| Key | Role |
|-----|------|
| `damage_cells` | Multiplier on max reach → mesh band `s_halo` (default `1.0`) |
| `surfaces.saw_cut.cell_size` | Override saw-cut halo |
| `surfaces.face.scale` | Face reach as fraction of saw-cut (default `0.25`) |
| `surfaces.face.enabled` | `false` → no halo on unsawn faces |
| `sampling.strategy` | `"exact"` or `"local_cloud"` (+ IDW) |
| `sampling.resolution` | Sub-points per axis for `local_cloud` (default `3`) |

`.with_halo(cell_size, face_enabled=..., sampling=...)` fills a sensible default
block; override via `CpropInput` only when needed.

## Backend and outputs

Halo needs per-Gauss-point stiffness → cases with `core.cell_size` **auto-route
to `numpy`**. Results include:

| Field | Meaning |
|-------|---------|
| `resin_vf` | Neat kerf resin volume fraction |
| `halo_vf` | Extra resin from opened cells |
| `effective_resin_vf` | `resin_vf + halo_vf` |
| `rho_infused` | Density including halo resin |

Engineering constants already embed the grade — **no separate halo layer** in
the global FEA model.

When mould curvature is set, the halo grades off the **tapered** wall `hw(z)` —
see [Halo + curvature](/docs/concepts/halo-curvature) (compose figures + Eyy vs
κ × cell_size).

See also [Visualization](/docs/guides/visualization#resin-halo-figures) and
[Agent use](/docs/guides/agent-use).
