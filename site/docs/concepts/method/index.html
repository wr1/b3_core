Periodic homogenization

RVE construction, six unit-strain load cases, and engineering constants.

Setup

For a periodic RVE under macroscopic strain ε̄, the displacement decomposes as

with ũ periodic. The mesh is a structured grid over [0, dx] × [0, dy] × [0, thickness] (optionally plus a thin top face layer for mesh stability). Cells are tagged:

TagMeaning
coreFoam / balsa bulk
resinInside a groove volume (neat kerf)
faceOptional stabilising face layer
halo bandGraded resin probability when cell_size is set

Grooves can be opened or closed by mould curvature (kx, ky): rectangular tags stay fixed, then an interval-affine wall morph moves faces so half-width tracks hw(z). Foam bays become trapezoidal on the flat RVE. See Kerf open & close. When a resin halo is also active, ScoreField distances use that same hw(z) so the graded band follows the tapered wall — Halo + curvature.

Six load cases

Each of six unit macroscopic strains is solved under periodic BC:

Load casePrimary outputs
xxExx, νxy (−εy/εx), νxz (−εz/εx)
yyEyy, νyx, νyz
zzEzz, νzx, νzy
xyGxy
xzGxz
yzGyz

In CalculiX, periodic coupling uses *equation cards that inject macro-strain via three dummy "strain nodes" tied to ± face node pairs. Solves run in parallel (process pool). From each VTU (or in-process field):

Geometric metrics

From analysis.geom_analysis:

  • resin_vf — resin volume / total RVE volume. Drives ρ_infused = ρ_core · (1 − vf) + ρ_resin · vf (halo resin is added when active).
  • area_increase — core surface area including groove walls, divided by the ungrooved top+bottom area 2·dx·dy. Useful for infusion / resin-uptake estimates.

Unit conventions

The mesh is built in mm and scaled by 1e-3 in the CCX writer so CalculiX sees SI everywhere.

What the global model sees

The homogenized properties replace the core layer in a sandwich or blade FEA model. Groove geometry is not re-meshed globally; only the smeared orthotropic solid (plus infused density) is exported.
