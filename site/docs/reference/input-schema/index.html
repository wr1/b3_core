Input schema

Full CpropInput field list (pydantic).

All geometry fields are mm. Material moduli are Pa, densities kg/m³.

Geometry

FieldTypeRole
dx, dy, thicknessfloatRVE size [mm]
xgr, ygrlist of [offset, spacing, depth, width]Groove families (empty = plain)
face{"thickness": mm}Optional stabilising face layer (default off)
curvature{"kx": 1/mm, "ky": 1/mm}Optional groove taper for curved panels
maddlist[float]Extra mesh-density knob (default [0])

Materials

core and resin accept either isotropic or orthotropic dicts:

Isotropic

Orthotropic (axes 1=x, 2=y, 3=z)

core may add cell_size — scalar or {mean, std, dist} — to enable the stochastic resin halo. See Resin halo. Combined with curvature, the halo grades off the tapered wall: Halo + curvature.

Scoring (halo)

FieldRole
scoring.damage_cellsReach multiplier for the mesh halo band
scoring.surfaces.saw_cut / facePer-surface overrides (cell_size, scale, enabled)
scoring.samplingstrategy: exact | local_cloud; resolution; idw_power

Requires core.cell_size. Auto-routes backend to numpy.
