Homogenize for FEA

Turn a case file into engineering constants, material cards, and FEA-ready handoff.

The primary product of b3_core is a smeared orthotropic core for a larger panel or blade model. Groove geometry stays in the RVE; the global model sees constants only.

Workflow

flowchart TB
  case[case.yaml / .json] --> run["b3_core run / homogenize()"]
  run --> eng[engineering constants]
  eng --> table[markdown table]
  eng --> card[JSON / CalculiX card]
  eng --> mat[OrthotropicMaterial]
  mat --> pipeline[b3_mat / b3_gx / section FEA]
  1. Write a CpropInput case (geometry + constituents).
  2. Run homogenization → run*.json / CoreResult.
  3. Hand off moduli + ρ to the structural model.
  4. Optionally attach a datasheet or gallery figure for review.

Halo cases

If core.cell_size is set (or constituents are orthotropic), the run auto-routes to the numpy backend. Results then also include halo_vf and effective_resin_vf. See Resin halo. With curvature too: Halo + curvature (Eyy / Vf vs κ × cell_size).
